# Project 0 media

Place the images and videos used by `0/index.html` in this directory.

Use short lowercase filenames with hyphens, for example:

- `close-up.jpg`
- `zoomed-in.jpg`
- `architecture-near.jpg`
- `architecture-far.jpg`
- `dolly-zoom.mp4`

Reference a file from `0/index.html` with a relative path such as `./media/close-up.jpg`.
